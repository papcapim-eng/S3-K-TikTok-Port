Estrutura:

- privacy/index.html

Publicação no GitHub Pages:
1. Crie um repositório público no GitHub (por exemplo: s3k-tiktok-port-legal).
2. Envie as pastas terms e privacy para a raiz do repositório.
3. Em Settings > Pages, escolha Deploy from a branch, selecione main e /(root).
4. Aguarde a publicação. Os endereços serão:
   https://SEU-USUARIO.github.io/s3k-tiktok-port-legal/terms/
   https://SEU-USUARIO.github.io/s3k-tiktok-port-legal/privacy/

ANTES DE PUBLICAR:
- Informe o nome do responsável e um e-mail/canal de contato válido.
- Identifique a rede/SDK de anúncios usada e adicione o link de sua política.
- Revise se o SDK coleta identificadores, IP, dados do dispositivo, localização ou eventos.
- Ajuste as declarações para refletir exatamente o funcionamento real do jogo.
- Verifique requisitos de consentimento, idade e LGPD aplicáveis.
